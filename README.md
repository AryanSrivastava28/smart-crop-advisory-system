# Smart Crop Advisory and Recommendation System

An intelligent agricultural platform that uses Machine Learning, Deep Learning, and environmental data to help farmers make better crop-related decisions. The system includes a React frontend and a Python FastAPI backend with trained ML/DL models.

## Features

- **Crop Recommendation** — Enter soil nutrients (NPK), pH, temperature, humidity, and rainfall to get a crop suggestion with confidence scores and environmental factor analysis. Powered by a Random Forest classifier trained on the Crop Recommendation Dataset.
- **Yield Prediction** — Predict expected crop yield based on crop type, area, rainfall, temperature, humidity, fertilizer usage, and season. Powered by a Keras deep learning neural network. Displays model validation metrics (R², MAE, RMSE) as reliability indicators rather than fabricated confidence percentages.
- **Farmer Advisory** — Get personalized, rule-based crop care suggestions including growing conditions, soil management, watering schedules, and pest management advice. This is a rule-based advisory system, not an ML model.
- **Weather-Based Advisory** — View sample weather conditions and receive agricultural advisories based on temperature, humidity, rainfall, and wind speed. Weather data is **sample/demo data**, not live API data.
- **Dashboard** — A unified view of all recommendations, predictions, soil summaries, weather conditions, and advisories with visual charts.

## Datasets

### Crop Recommendation Dataset
- **Source:** [Kaggle — Crop Recommendation Dataset](https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset)
- **Size:** 2,300 samples, 23 crop classes
- **Features:** N, P, K, temperature, humidity, ph, rainfall, label (crop)
- **Location:** `backend/datasets/Crop_recommendation.csv`

### Crop Yield Dataset
- **Source:** Generated based on realistic agricultural yield patterns for Indian crops (FAO/Indian agriculture reference data)
- **Size:** 1,584 samples, 8 crops, 3 seasons
- **Features:** crop, area, rainfall, temperature, humidity, fertilizer, season, yield (target)
- **Location:** `backend/datasets/crop_yield_data.csv`

## Preprocessing

- **Numerical features:** Standardized using `StandardScaler` (fitted on training data only)
- **Categorical features:** One-hot encoded using `OneHotEncoder` (fitted on training data only)
- **Train/test split:** 80/20 with `random_state=42`
- **No data leakage:** Scalers and encoders are fitted on training data only, then applied to test data via `transform()`

## Machine Learning Models

### Crop Recommendation (Classification)
- **Model:** Random Forest Classifier (100 estimators, max depth 15)
- **Comparison:** Also trained Logistic Regression as baseline; Random Forest selected as best
- **Evaluation:** Accuracy, classification report
- **Artifacts:** `backend/ml_models/crop_model.joblib`, `crop_scaler.joblib`, `crop_metadata.joblib`

### Yield Prediction (Regression — Deep Learning)
- **Model:** Keras Sequential neural network (128 → 64 → 32, ReLU, BatchNorm, Dropout)
- **Training:** MSE loss, Adam optimizer, EarlyStopping (patience=10), ReduceLROnPlateau
- **Evaluation metrics:** MAE, RMSE, R²
- **Artifacts:** `backend/ml_models/yield_model.keras`, `yield_scaler.joblib`, `yield_encoder.joblib`, `yield_metadata.json`

## ML Baseline vs Deep Learning Comparison

Three ML baselines were trained on the same yield dataset and compared with the DL model:

| Model | MAE | RMSE | R² |
|-------|-----|------|-----|
| Linear Regression | 1.6288 | 3.7478 | 0.9622 |
| Random Forest | 0.8385 | 2.2756 | 0.9861 |
| Gradient Boosting | 0.6856 | 2.1024 | 0.9881 |
| Deep Learning (Keras) | 1.5395 | 2.4872 | 0.9834 |

Results are generated by running `backend/training/analysis/baseline_comparison.py`.

## Hyperparameter Tuning

A lightweight grid search was performed testing 6 configurations:
- Learning rates: 0.001, 0.0005
- Dropout rates: 0.10, 0.15, 0.20
- Hidden layer sizes: (128,64,32), (64,32,16)

**Best configuration:** lr=0.001, dropout=0.20, sizes=(128,64,32), val_loss=1.4717

Results saved at `backend/training/analysis/tuning_figures/tuning_results.json`.

## Overfitting Analysis

The training vs validation curves show a generalization gap, which is expected for a neural network on a relatively small dataset (1,584 samples). The model uses Dropout and EarlyStopping to mitigate overfitting. Test R² remains high at 0.987, indicating the model generalizes well despite the training/validation gap.

Analysis saved at `backend/training/analysis/training_figures/overfitting_analysis.json`.

## Yield Prediction Reliability

The Yield Prediction page displays **model validation metrics** (R², MAE, RMSE) as reliability indicators, not a fabricated confidence percentage. These metrics are read from the trained model's metadata file and reflect actual test set performance.

## Weather Data

Weather advisory uses **sample/demo data** generated with realistic ranges, not a live weather API. The UI clearly labels this as "Sample Data (Demo Mode)". The advisory rules (rainfall, temperature, humidity thresholds) are fully functional.

## Farmer Advisory

The Farmer Advisory is a **rule-based system**, not an ML model. It uses crop-specific optimal condition tables and threshold-based rules to generate advice. It is not labeled as AI/ML prediction.

## Setup

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

### Frontend

```bash
npm install
npm run dev      # development
npm run build    # production build
```

### Environment Variables

Create a `.env` file in the project root:

```env
VITE_API_BASE_URL=http://localhost:8000
```

When `VITE_API_BASE_URL` is not set, the frontend uses built-in mock data with graceful fallback.
